# Foodwala — Food Ordering Web Application

Foodwala is a food ordering web application developed using Java, JSP, Servlets, and MySQL.

## Technologies Used
- Java
- JSP and Servlets
- HTML and CSS
- MySQL
- Apache Tomcat
- Eclipse IDE

## Features
- Browse restaurants
- View restaurant menus
- Add items to the cart
- Proceed to checkout
- Manage orders
- User login and registration

## Database Setup
1. Create a MySQL database named `foodwaladatabase`.
2. Set up the required tables and restaurant/menu data.
3. Configure your local database credentials.
4. Never upload passwords or access tokens to GitHub.

## How to Run
1. Import the project into Eclipse.
2. Configure the JDK and Apache Tomcat.
3. Set up the MySQL database.
4. Configure the database connection.
5. Run the application on Tomcat.
